# Uday Banduni - Personal Portfolio Website 🚀

Welcome! This is the repository containing the source code for my personal portfolio website.

---

## ⚙️ Tech Stack

React • TypeScript • GSAP • Three.js • WebGL • HTML • CSS • JavaScript

---

## 🛠️ Highlights

* **Interactive 3D Character:** Dynamic character with typing, look-at, and blink animations built using Three.js and `@react-three/fiber`.
* **Physics-Based Canvas:** Technology ball simulation with collision physics and cursor response powered by `@react-three/rapier`.
* **Smooth Animation System:** Interactive scroll transitions and custom cursor animations implemented with GSAP.
* **Responsive Layout:** Sleek modern typography and layouts written in vanilla CSS.

---

## ⚙️ Development Setup

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm run dev
```

Build the production bundle:

```bash
npm run build
```
